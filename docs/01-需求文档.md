# 01 · 需求文档（PRD）

> 项目：阿拉伯数字 → 中文大写金额转换 App
> 文档版本：v1.0
> 最后更新：2026-06-20
> 状态：已确认

## 1. 项目背景

在财务、税务、合同、发票等场景中，常常需要把阿拉伯数字金额写成中文大写形式（如发票上的"金额大写"栏），以防篡改。本项目为 **离线 iOS 工具**，帮助用户快速完成转换。

## 2. 目标用户

- **个人**：写收据、记账时需要大写金额
- **财务人员**：日常开票
- **自由职业者 / 小商户**：签合同、收款时
- **不写代码的人**：通过 vibe coding 完成

## 3. MVP 核心功能（In Scope）

| 编号 | 功能 | 说明 |
| ---- | ---- | ---- |
| F1   | 数字输入 | 数字键盘，支持小数（最多 2 位） |
| F2   | 转换   | 点击「转换」按钮，输出中文大写 |
| F3   | 复制   | 一键复制结果到系统剪贴板 |
| F4   | 清除   | 一键清空输入和结果 |
| F5   | 错误提示 | 输入非法字符或超大数时给出友好提示 |
| F6   | 示例   | 提供"试试看"按钮，一键填入示例数字 |

## 4. 非 MVP 功能（Out of Scope · 暂不做）

- 历史记录列表
- 多语言（仅中文）
- 货币符号（¥ / $）
- 负数（财务场景几乎不用）
- 科学计数法
- 网络同步
- 暗色模式自定义（先跟随系统）
- 桌面小组件
- Apple Pencil 支持

## 5. 用户故事

| 编号 | 故事 |
| ---- | ---- |
| US1  | 作为一个用户，我想输入 `1234.56` 后立即看到 `壹仟贰佰叁拾肆元伍角陆分`，以便我填写发票。 |
| US2  | 作为一个用户，我想一键复制转换结果，避免我手动输入容易出错。 |
| US3  | 作为一个用户，我输入空或非法字符时，应用应提示我，而不是闪退。 |
| US4  | 作为一个用户，我想点击「清除」快速重新开始。 |
| US5  | 作为一个首次使用者，我想点一下"试试看"先看到效果，再自己输入。 |
| US6  | 作为一个用户，输入 `100000000.99`（一亿零九角九分）转换结果应正确。 |

## 6. 验收标准（MVP Done 的定义）

- [ ] iOS 17+ 模拟器可正常运行
- [ ] 输入常见数字（0 / 100 / 1234.56 / 100000000.99 / 0.05）转换结果与 `05-测试用例.md` 完全一致
- [ ] 复制按钮可一键复制，粘贴到备忘录可读
- [ ] 输入非法字符不会闪退，且给出提示
- [ ] 输入为空时点击「转换」不闪退，给出提示
- [ ] UI 符合 `03-设计规范.md`
- [ ] 单元测试覆盖率 ≥ 80%

## 7. 明确不做（范围之外）

- 任何 iOS 版本低于 17 的兼容
- App Store 发布
- 后端 / 云服务 / 账户体系
- 任何 iCloud 同步
- 任何内购 / 订阅
