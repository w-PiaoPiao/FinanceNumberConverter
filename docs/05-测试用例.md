## B. 输入校验测试（阶段 4 验收）

| 输入 | 期望行为 |
| --- | --- |
| 空字符串 | 不报错，提示"请输入金额" |
| `abc` | 拒绝转换，提示"仅支持数字" |
| `-100` | 拒绝，提示"不支持负数" |
| `1.234` | 拒绝 / 自动截断为 `1.23` |
| `10000000000000`（> 万亿）| 拒绝，提示"金额过大" |
| `1.` | 视为 `1`，输出"壹元整" |
| `.5` | 视为 `0.5`，输出"零元伍角" |
| `1.05.6` | 拒绝，提示"数字格式错误" |
