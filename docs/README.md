## 一、项目一句话

把阿拉伯数字金额（如 `1234.56`）实时转换为中文财务大写（如 `壹仟贰佰叁拾肆元伍角陆分`），方便填写发票、合同、收据等场景。

## 四、工作原则

1. **严格按 `04-开发执行步骤.md` 推进**，每阶段完成并通过验收才进入下一阶段
2. **一次只做 1 个原子任务**，完成并验证后再进下一项
3. **任何代码改动前先在 dev-logs 中列出计划**
4. **不在未读相关文档的情况下动手**
5. **不在未与用户确认的情况下越界**
