## 阶段 1 · Xcode 工程初始化

**状态**：⏳ 待开始

**目标**：在 Xcode 里能跑出空白 App

**前置**：阶段 0 验收通过

**具体步骤**：
1. 打开 Xcode → Create New Project
2. 选择 iOS → App
3. 配置：
   - Product Name: `FinanceNumberConverter`
   - Interface: SwiftUI
   - Language: Swift
   - Storage: None
   - Deployment Target: iOS 17.0
   - Bundle Identifier: `com.example.FinanceNumberConverter`（临时占位，待用户确认）
4. 保存到项目根目录的 `FinanceNumberConverter/` 子目录
5. 选择 iPhone 15 模拟器
6. 点击 ▶ 运行，确认出现默认 SwiftUI 界面

**产出**：
- `FinanceNumberConverter/FinanceNumberConverter.xcodeproj`
- 模拟器跑通

**验收**：
- [ ] 模拟器显示 SwiftUI 默认界面
- [ ] 工程可关闭、重开、再运行
- [ ] 工程目录位于项目根下

**风险**：
- Bundle ID 需要唯一（首次可临时用 `com.example.*`）
- 工程文件路径含中文目录可能引起 Xcode 警告（但能跑）

**Commit**：`chore: 创建 Xcode 工程并跑通 Hello World`

## 阶段 2 · 核心转换逻辑

**状态**：⏳ 待开始

**目标**：实现无 UI 依赖的金额转大写纯函数 + 单元测试

**前置**：阶段 1 验收通过

**具体步骤**：
1. 新增 `NumberConverter.swift`
2. 实现：
   - `static func convert(_ amount: Decimal) -> String`
   - 内部子函数（拆分整数/小数、处理零、拼接单位）
3. 新增 `NumberConverterTests.swift`
4. 编写单元测试覆盖 `05-测试用例.md` 中所有 A 段用例
5. 运行 `Cmd+U` 跑测试

**产出**：
- 100% 命中的单元测试

**验收**：
- [ ] 所有 `05-测试用例.md` A 段用例全部通过
- [ ] 测试覆盖率 ≥ 80%
- [ ] `NumberConverter.swift` 无任何 UI 引用（`import Foundation` 即可）

**风险**：
- 转换规则边界 case 多（连续零、末尾零、整数位空等），需细致
