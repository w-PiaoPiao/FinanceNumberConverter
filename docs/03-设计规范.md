# 03 · 设计规范

> 项目：阿拉伯数字 → 中文大写金额转换 App
> 文档版本：v1.0
> 最后更新：2026-06-20
> 状态：已确认

## 1. 设计原则

- **简洁**：单屏完成所有操作，无 Tab 无导航
- **直观**：所见即所得，输入和结果同屏
- **现代**：iOS 原生设计语言（System Colors、SF Pro）
- **大字号**：结果区文字至少 28pt，方便查看

## 2. 颜色规范

| 名称 | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| Primary | #007AFF | #0A84FF | 按钮、链接 |
| Background | #F2F2F7 | #000000 | 背景 |
| Surface | #FFFFFF | #1C1C1E | 卡片 |
| Text Primary | #000000 | #FFFFFF | 主要文字 |
| Text Secondary | #8E8E93 | #8E8E93 | 次要文字 |
| Divider | #C6C6C8 | #38383A | 分割线 |
| Success | #34C759 | #30D158 | 复制成功提示 |
| Error | #FF3B30 | #FF453A | 错误提示 |

> 优先使用 SwiftUI 内置语义色：`Color.accentColor`、`.secondary`、`.tertiary`，避免硬编码 hex。

## 3. 字体规范

使用系统字体（San Francisco / 苹方）。

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 标题（页面顶部） | 17pt | Semibold |
| 输入框 | 24pt | Regular |
| 转换按钮文字 | 17pt | Semibold |
| 结果展示 | 32pt | Semibold |
| 次要说明文字 | 13pt | Regular |
| 错误提示 | 13pt | Regular |

## 4. 间距规范

| 名称 | 数值 | 用途 |
| --- | --- | --- |
| xs | 4pt | 极小间距 |
| s | 8pt | 文字间小距 |
| m | 16pt | 元素间距 |
| l | 24pt | 区块间距 |
| xl | 32pt | 大区块间距 |
| xxl | 48pt | 页面顶部留白 |

## 5. 圆角规范

- 按钮：12pt
- 输入框：10pt
- 卡片：16pt
- 标签：6pt

## 6. 关键页面布局

### 6.1 主界面（单屏）

```
┌─────────────────────────────┐
│   财务大写转换                │  ← 标题 (17pt Semibold)
│                             │
│   ┌───────────────────────┐ │
│   │  请输入金额             │ │  ← 输入框 (24pt)
│   └───────────────────────┘ │
│                             │
│   [   转换为大写   ]         │  ← 主按钮（实心）
│   [   试试看   ] [   清除   ]│  ← 次要按钮（描边）
│                             │
│  ─────────────────────────  │  ← 分割线
│                             │
│   壹仟贰佰叁拾肆元伍角陆分    │  ← 结果 (32pt Semibold)
│                             │
│   [   一键复制   ]           │  ← 复制按钮（结果出现后显示）
│                             │
└─────────────────────────────┘
```

### 6.2 状态说明

| 状态 | 描述 |
| --- | --- |
| **初始** | 输入框空，提示"请输入金额"，不显示结果区 |
| **输入中** | 实时校验，非法时输入框红边 + 错误提示 |
| **转换后** | 显示结果 + 复制按钮，3 秒内显示"已复制"反馈 |
| **错误态** | 底部 Toast 提示错误原因，3 秒后消失 |

## 7. 交互规范

- **输入框**：打开 App 时自动获得焦点
- **键盘**：`.decimalPad`
- **按钮反馈**：按下时透明度 0.7，松开恢复
- **复制反馈**：按钮文字变为"✓ 已复制" 2 秒后恢复
- **清除**：二次确认（弹出 Alert）防误触

## 8. 无障碍

- 所有可点击元素 ≥ 44×44pt
- 文字对比度 ≥ 4.5:1
- 支持 Dynamic Type
- VoiceOver 标签完整
