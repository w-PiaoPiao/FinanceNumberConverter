# 财务大写转换 App

> iOS App · 阿拉伯数字 → 中文大写金额转换工具

## ✨ 项目简介

把阿拉伯数字金额（如 `1234.56`）实时转换为中文财务大写（如 `壹仟贰佰叁拾肆元伍角陆分`），方便填写发票、合同、收据等场景。

- **平台**：iOS 17+
- **技术栈**：Swift + SwiftUI（零三方依赖）
- **学习项目**：纯本地，零基础 vibe coding 实战

## 🚀 快速开始

```bash
# 查看提交历史
git log --oneline

# 用 Xcode 打开工程（阶段 1 之后）
open FinanceNumberConverter/FinanceNumberConverter.xcodeproj
```
