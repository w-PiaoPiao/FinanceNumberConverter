## 💡 想法 & 备注
- 决策记录：
  - 技术栈：ArkTS + ArkUI + Stage 模型
  - 工具：DevEco Studio 5.0+（用户未装，需先装，约 2.5GB）
  - 真机：无（只能用模拟器）
  - 代码迁移：1:1 重写 ArkTS（与 iOS/Android 并列）
  - 项目结构：并列（`./harmony/`）
- 与 iOS / Android 关键差异：
  - **数字类型**：ArkTS 用 `number`（双精度），财务场景需手动截断到分
  - **入口**：Stage 模型的 `UIAbility`（不是 Activity / App）
  - **状态管理**：`@State` 装饰器（与 SwiftUI 接近）
  - **测试**：Hypium 框架（与 XCTest / JUnit 概念相似但 API 不同）
  - **构建**：Hvigor（类似 Gradle）
- 用户没有真机 → 只能模拟器演示（功能完整但不能"装到手机"）
- 鸿蒙 NEXT 生态年轻，文档较少，遇到坑及时沟通
