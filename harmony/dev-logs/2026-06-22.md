## 🐛 遇到的问题与解决

- **opencode 客户端项目路径缓存旧值**
  - 原因：项目目录从 `第一个ios项目` 改名为 `FinanceNumberConverter` 后，opencode 客户端缓存未刷新
  - 解决：客户端侧点"项目路径修改/替换"（用户操作）

- **build-profile.json5 targetSdkVersion 错误**（"1" → "5.0.0(12)"）
  - 错误：Specification Limit Violation
  - 解决：改成 `5.0.0(12)` 格式

- **ohosTest target 不能进 product 打包**
  - 错误：'ohosTest' target does not need to be packaged
  - 解决：根 build-profile.json5 移除整个 ohosTest 块（test target 只在 entry/build-profile.json5 声明）

- **14 项 ArkTS 编译错误**（详见 commit `fix(harmony): 阶段 1 验收 6 项 ArkTS 编译/运行错误`）
  - NumberConverter 解构赋值不支持 → 显式索引
  - InputType.Decimal 不存在 → InputType.Normal
  - Stack.justifyContent 不存在 → Stack.alignContent(Alignment.Center)
  - Column-inside-Column 嵌套让 ArkTS 误解属性归属 → 重构为 Stack + 两个平级子组件
  - pasteboard.Pasteboard.setPlainText API 不存在 → SystemPasteboard + createData + setData
  - text: this.input 单向绑定 → 改 $$this.input 双向绑定
  - focusControl.requestFocus 未 import → .defaultFocus(true)
  - helpText getter 在某些情况下不重渲染 → 改 method

- **「输入 ss 字母被快速删除」现象**
  - 原因：旧版 `text: this.input` 单向绑定，sanitize 已去除字母但显示未更新
  - 解决：$$this.input 双向绑定

- **「提示文字看不到」问题**
  - 原因 1：getter 不触发重渲染（部分场景）
  - 原因 2：build 缓存旧 HAP
  - 解决：改 method + 加大背景色 + 用户 Clean + Rebuild + 卸载重装
