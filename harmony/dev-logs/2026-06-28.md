## 🐛 遇到的问题与解决

- **ArkTS 类型导入选择**
  - `UIAbilityContext` 类型需从 `@ohos.app.ability.common` 导入（default export + 命名空间访问）
  - `terminateSelf()` 在 `UIAbilityContext` 上，不在 `Context` 上
  - 解决：`import common from '@ohos.app.ability.common'` + `(getContext() as common.UIAbilityContext).terminateSelf()`

- **持久化存储选型**
  - 需要记录用户是否已同意隐私政策
  - 选项：`@ohos.data.preferences`（KV 存储） / `@ohos.data.relationalStore`（DB）
  - 选 preferences：轻量，适合单键值对，与项目"无三方依赖"原则一致
  - 存储 key：`privacy_policy_accepted`，value：boolean

- **弹窗模式选择**
  - 选项：CustomDialogController / Stack overlay
  - 选 Stack overlay：与项目现有 AlertDialogView 模式一致，避免新增 controller 复杂度
