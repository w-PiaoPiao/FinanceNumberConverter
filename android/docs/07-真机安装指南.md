# 07 · 真机安装指南

> 项目：阿拉伯数字 → 中文大写金额转换 App（Android 端）
> 文档版本：v1.0
> 最后更新：2026-06-21
> 适配机型：nubia（MyOS）+ vivo（OriginOS）等国产深度定制系统

## 0. 前提

- ✅ 已构建 `app-release.apk`（40MB，已签名）
  - 路径：`android/app/build/outputs/apk/release/app-release.apk`
- ✅ 一台安卓 15/16 国产手机（nubia MyOS / vivo OriginOS）

## 1. 三种 APK 传输方式

### 方式 A：USB 数据线（**最稳定、最快**）

**Mac 步骤**：
1. 用 USB-C 数据线连接 Mac 和手机
2. 手机弹出"USB 用途"通知 → 选择 **"传输文件 / MTP"**
3. Mac 上打开 **Finder**，侧栏会显示手机
4. 把 `app-release.apk` 拖到手机的 `Download` 文件夹
5. 在手机文件管理器中找到 APK → 点击安装

**如果 Mac 找不到手机**：
- 安装 [Android File Transfer](https://www.android.com/filetransfer/)（Google 官方）
- 打开它 → 拖入 APK
- **注**：新版 macOS 已内置类似功能，无需第三方工具

### 方式 B：微信文件传输助手

**Mac 步骤**：
1. 打开 Mac 微信
2. 进入"文件传输助手"（自己跟自己）
3. 发送 `app-release.apk` 文件
4. 手机微信收到文件
5. **关键步骤**：长按文件 → **"另存为"** → 保存到 `Download` 文件夹
6. 在手机文件管理器中找到 APK → 点击安装

⚠️ **不能直接点开**：微信会修改 APK 文件名（如 `app-release.apk.1`），直接点开会失败。必须**另存为**。

### 方式 C：网盘（iCloud Drive / 极空间云盘）

**Mac 步骤**：
1. 把 `app-release.apk` 拖到 iCloud Drive / 极空间 / OneDrive 等
2. 手机打开同名云盘 App
3. 下载 APK 到 `Download` 文件夹
4. 在手机文件管理器中找到 APK → 点击安装

## 2. 安装流程（nubia MyOS / vivo OriginOS）

### 步骤 1：开启"未知来源"权限

这一步**国产手机必做**，否则系统会拒绝安装。

#### 2.1 nubia（MyOS）路径

1. 打开手机 **"设置"**
2. 搜索 **"未知应用安装"** 或 **"安装未知应用"**
3. 选择**你用来打开 APK 的 App**（一般是"文件管理"）
4. 把开关 **打开**
5. 返回桌面

**或路径**（部分 MyOS 版本）：
设置 → 安全与隐私 → 未知来源 → 开关打开

#### 2.2 vivo（OriginOS）路径

1. 打开 **"设置"**
2. 搜索 **"未知应用安装"** 或 **"安装未知应用"**
3. 选择**用来打开 APK 的 App**（"文件管理"或"浏览器"）
4. 把开关 **打开**
5. 返回桌面

**或路径**（OriginOS Ocean）：
设置 → 安全与隐私 → 更多安全设置 → 未知来源

#### 2.3 通用步骤（首次点击 APK 时）

1. 在手机文件管理器中点击 `app-release.apk`
2. 系统弹窗"此来源未知，是否允许？"
3. 点击 **"设置"** → 开启权限
4. 返回 → 重新点击 APK

### 步骤 2：安装 APK

1. 文件管理器点击 `app-release.apk`
2. 系统弹出安装预览（显示 App 名"财务大写转换"、版本"1.0"、权限）
3. 点击 **"安装"**
4. 等待 3-5 秒（首次安装会慢）
5. 弹出"安装完成" → 点击 **"完成"** 或 **"打开"**

### 步骤 3：首次打开 + 验证

1. 在桌面找到 **"财务大写转换"** 图标（暖白底 + 壹字）
2. 点击打开
3. **首次启动权限**：无（App 不需要任何权限）
4. 应该看到：
   - 标题"财务大写转换"
   - 副标题"金额大写转换" + 右侧"Designed by Piao · Powered by opencode"
   - 输入框、转换按钮

### 步骤 4：测试核心功能

| 测试项 | 操作 | 期望 |
| --- | --- | --- |
| 基本转换 | 输入 1234.56 → 转换 | 显示"壹仟贰佰叁拾肆元伍角陆分" |

## 3. 常见问题

### Q1: 安装时提示"应用未安装"

**原因**：签名冲突（之前装过同包名但不同签名的版本）

**解决**：
1. 设置 → 应用 → "财务大写转换" → 卸载
2. 重新点击 APK 安装

### Q2: 安装时提示"解析包出现问题"

**原因**：APK 损坏（传输不完整）

**解决**：
1. 检查 APK 大小（应该 ~40MB，不是 0 字节）
2. 重新传输（推荐 USB）
3. 如果用微信，确保**另存为**（不要直接点）

### Q3: 安装成功但图标是 Android 默认的，不是"壹"字

**原因**：adaptive icon 在某些启动器上显示异常

**解决**：
- 重启手机
- 或换个启动器（如 Nova Launcher）

### Q4: 打开 App 闪退

**原因**：可能是 targetSdk 35 兼容性问题

**解决**：
- 在桌面长按 App 图标 → 应用信息 → 清除数据
- 重新打开
- 如果仍闪退，告诉我，我调整 targetSdk

### Q5: "未知来源"开关打不开（vivo 部分机型）

**原因**：vivo 部分机型需要先登录 vivo 账号

**解决**：
1. 设置 → 账号与同步 → 注册/登录 vivo 账号
2. 重新打开"未知来源"开关

### Q6: 输入数字时键盘不是数字键盘

**原因**：极少见的系统兼容问题

**解决**：
- 清除 App 数据后重启

## 4. 升级 / 重新安装

**同一 keystore 签名的 APK 可直接覆盖安装**（升级）：
1. 接收新的 `app-release.apk`
2. 点击安装 → 系统检测到同包名 + 同签名 → 直接升级
3. 保留历史记录等所有数据

**如果 keystore 不同**（即用户改了密码或重新生成）：
1. 必须先卸载旧版 → 再装新版
2. 所有数据丢失

## 5. 卸载

- 长按 App 图标 → 卸载
- 或：设置 → 应用 → "财务大写转换" → 卸载
