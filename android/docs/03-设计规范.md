# 03 · Android 设计规范

> 项目：阿拉伯数字 → 中文大写金额转换 App（Android 端）
> 文档版本：v1.0
> 最后更新：2026-06-21
> 状态：已确认

## 1. 设计原则

与 iOS 一致：
- **简洁**：单屏完成所有操作
- **直观**：输入和结果同屏
- **现代**：Material 3 设计语言
- **大字号**：结果区至少 28sp

## 2. 颜色规范

与 iOS 暖白主题一致：

| 名称 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| Primary | #007AFF | #0A84FF | 按钮、链接 |
| Background | #F2F2F7 | #000000 | 背景（暖白）|
| Surface | #FFFFFF | #1C1C1E | 卡片 |
| Text Primary | #000000 | #FFFFFF | 主要文字 |
| Text Secondary | #8E8E93 | #8E8E93 | 次要文字 |
| Divider | #C6C6C8 | #38383A | 分割线 |
| Error | #FF3B30 | #FF453A | 错误提示 |
| Success | #34C759 | #30D158 | 复制成功 |

> 优先使用 Material 3 语义色（`MaterialTheme.colorScheme.surface` 等）

## 3. 字体规范

使用系统字体（Roboto / 思源黑体）。

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 标题（页面顶部） | 28sp | Bold |
| 输入框 | 24sp | Normal |
| 转换按钮文字 | 17sp | SemiBold |
| 结果展示 | 28sp | SemiBold |
| 副标题 | 13sp | Normal |
| 错误提示 | 13sp | Normal |
| 副标题声明 | 10sp | Normal |

## 4. 间距规范

| 名称 | 数值 | 用途 |
| --- | --- | --- |
| xs | 4dp | 极小间距 |
| s | 8dp | 文字间小距 |
| m | 16dp | 元素间距 |
| l | 24dp | 区块间距 |
| xl | 32dp | 大区块间距 |

## 5. 圆角规范

- 按钮：10dp
- 输入框：10dp
- 卡片：10dp
- 标签：6dp

## 6. 关键页面布局

### 6.2 状态说明

| 状态 | 描述 |
| --- | --- |
| **初始** | 输入框空，提示"请输入金额" |
| **输入中** | 实时校验，非法时输入框红边 + 错误提示 |
| **转换后** | 显示结果 + 复制按钮，复制后显示"已复制" |
| **错误态** | 下方红字提示，3 秒后不变（Compose 需手动清除）|

## 7. 交互规范

- 输入框：自动获得焦点（打开 App 时）
- 键盘：`KeyboardType.Decimal`
- 按钮反馈：按下时透明度 0.7
- 复制反馈：按钮文字变为"✓ 已复制" 2 秒后恢复
- 清除：二次确认（`AlertDialog`）

## 8. App Icon（Android Adaptive Icon）

- **背景**：暖白 `#F2F0EB`（与 iOS 一致）
- **前景**：黑色"壹"字
- **形状**：由系统决定（圆/方/圆角方）
- **尺寸**：
  - 108×108dp（前景 + 背景）
  - 72×72dp 中心安全区（重要内容放这里）

| 圆角 | 10pt | 10dp | ✅ |
| 标题字号 | 28pt | 28sp | ✅ |
| 结果字号 | 28pt | 28sp | ✅ |
